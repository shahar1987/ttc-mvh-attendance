# commander-waiting

מוד ל-Claude Code שמתריע כשהמפקד עוצר ומחכה לך — כדי שלא תצטרך לבדוק כל כמה דקות.

מתי הוא מתריע:
- ❓ **צריך החלטה** — או כשנפתחת שאלה עם אפשרויות לבחירה.
- ✅ **מוכן לשחרור** — מחכה ל"כן".
- ⚠️ **נתקע**.

מה קורה:
- פס צבעוני מעל הפרומפט: "המפקד מחכה לך" + השורה מההודעה (כחול/ירוק/כתום).
- התראת מערכת (או הודעה קופצת אם אין), וצליל קצר (ב-Mac).
- הפס נעלם ברגע שאתה עונה.
