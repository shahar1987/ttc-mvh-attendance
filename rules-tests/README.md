# בדיקות לכללי האבטחה

הבדיקות מריצות את אמולטור Firestore מקומית מול `../firestore.rules` ומוודאות
שכל תרחיש שחשוב לנו באמת מתנהג כמו שצריך: מה הורה רואה ומה לא, מה מאמן יכול
לשנות, שהרשמה דרך קישור הזמנה עובדת מקצה לקצה, ושאי אפשר לנצל אותה כדי
להעניק לעצמך תפקיד או להתקשר לילד של מישהו אחר.

```
cd rules-tests
npm install
npm test
```

דורש Java מותקן (האמולטור רץ עליו). הבדיקות רצות אוטומטית ב-GitHub Actions
בכל דחיפה שנוגעת ב-`firestore.rules`.

**חשוב:** בדיקה ירוקה אומרת שהקובץ תקין — היא לא מפרסמת כלום.
הפרסום בפועל נעשה ידנית בקונסולה: Firestore Database ⟵ Rules ⟵ Publish.
